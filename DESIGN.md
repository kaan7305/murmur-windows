# Design rules

Rules, not suggestions. If something on screen breaks one of these, it is wrong
and gets changed.

## 1. Only text that is absolutely necessary

Every string has to earn its place by answering a question the user is actually
asking at that moment. If it explains, reassures, justifies, or sells, cut it.

The test: **delete the line. Is the user now unable to do something, or about to
do the wrong thing?** If not, it stays deleted.

Cut on sight:

- Restating what the screen already shows. A page called Models library does not
  need a line under it saying these are the models.
- Reassurance. "Free to use", "and kept afterwards", "no account needed" — say
  it once, in one place, never on every screen.
- Explaining the mechanism when the outcome is what matters. Nobody choosing a
  model wants a paragraph on where it is downloaded from.
- Three sentences where the label already said it. `Tiny — Answers instantly`
  is the whole thought. What followed it was two more sentences saying the same
  thing at greater length.
- Adjectives doing no work. "Powerful", "seamlessly", "simply", "just".

A screen that reads like a brochure reads like nobody chose the words. Density
of *information* is good; density of *prose* is not.

## 2. No decorative badges

A coloured word inside a coloured box, next to the thing it describes, is
noise. `Fastest` in green type on a green field, beside a model whose speed is
already written next to it in numbers, tells the reader nothing they did not
already have and makes the page look assembled from a component kit.

Status may be shown when it is *state the user can act on* — In use, Not
connected, On. Never as a label restating an attribute already visible in the
row.

If a badge survives, it is one weight of one colour, never a colour-on-colour
wash per category.

## 3. Fit on the screen

If a list needs scrolling to see items that should be comparable, the rows are
too tall. Cutting text (rule 1) is the first lever; tightening padding is the
second. Six models should be visible at once, because choosing between them
means seeing them together.

## 4. One voice, plainly

Sentence case. No exclamation marks. No em-dash asides where a full stop works.
Contractions are fine. Address the reader as *you* only when giving an
instruction.

## 5. Colour means something

The accent colour marks the thing in use or the action to take. It is not
decoration and it does not get spent on category labels, section headings, or
chips. A page with six accent-coloured elements has none.

---

Applied to this repository: the models list carried a page subtitle, a note and
a detail paragraph per model, and a coloured tier badge per model — around 400
words to choose between six items that differ in two numbers. All of it went.
